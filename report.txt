PROJECT SYNOPSIS REPORT: B2B BOLT

---

1. ABSTRACT

The rapid growth of digital commerce has highlighted a need for specialized platforms catering to Business-to-Business (B2B) transactions. This project, "B2B BOLT," presents the design and development of a full-stack e-commerce web application tailored for the B2B market. The platform is built using the PERN stack (PostgreSQL/MySQL, Express.js, React.js, Node.js) and features a robust, role-based access control system for three distinct user types: Retailers, Sellers, and Administrators. Key functionalities include secure user authentication, comprehensive product and inventory management for sellers, a streamlined browsing and ordering process for retailers, and a powerful administrative dashboard for platform oversight. The system aims to provide a scalable, secure, and user-friendly solution that facilitates efficient trade between business entities, addressing the common gaps found in generic B2C or overly complex enterprise-level systems. The expected outcome is a fully functional prototype demonstrating the viability of a dedicated B2B e-commerce ecosystem.

---

2. INTRODUCTION

Background:
In the current digital economy, e-commerce is no longer limited to consumer-facing retail. The Business-to-Business (B2B) e-commerce sector is expanding at an unprecedented rate, yet many small to medium-sized enterprises (SMEs) still rely on outdated methods like phone calls, emails, or generic B2C platforms that are ill-suited for their needs. B2B transactions involve different complexities, such as bulk ordering, role-based purchasing permissions, and distinct user relationships (e.g., sellers and retailers). This project is important as it addresses this market gap by creating a purpose-built platform that understands and serves the unique dynamics of B2B commerce.

Problem Definition:
The primary problem is the lack of accessible, efficient, and scalable e-commerce solutions specifically designed for B2B interactions. Existing platforms are often either too complex and expensive for smaller businesses or are simply B2C platforms retrofitted with minimal B2B features. This leads to inefficiencies in order management, inventory tracking, and user administration. "B2B BOLT" aims to solve this by providing a centralized platform where sellers can manage their products and retailers can easily place orders, all under the supervision of a platform administrator.

---

3. OBJECTIVES

The primary objectives of the "B2B BOLT" project are:

- **Objective 1:** To design and develop a secure, multi-user backend system with role-based access control (RBAC) for Retailer, Seller, and Admin roles using Node.js, Express.js, and Sequelize ORM with a MySQL database.

- **Objective 2:** To create a responsive and intuitive frontend application using React.js, providing separate, tailored dashboard experiences for each user role to perform their respective tasks efficiently.

- **Objective 3:** To implement core e-commerce functionalities, including product catalog management, a multi-step ordering process, user profile management, and order history tracking.

- **Objective 4:** To build a comprehensive administrative module for platform oversight, including user management (viewing, activating/deactivating, deleting users) and viewing platform-wide statistics.

6. METHODOLOGY

Tools & Technologies:
- **Backend:** Node.js, Express.js, Sequelize (ORM), MySQL
- **Frontend:** React.js, Vite, Tailwind CSS, React Query
- **Authentication:** JSON Web Tokens (JWT)
- **External APIs:** Twilio for SMS notifications
- **Development Environment:** Visual Studio Code, Git, GitHub

System Architecture:
The project follows a classic client-server architecture.
- **Client (Frontend):** A single-page application (SPA) built with React.js that renders the UI in the user's browser. It communicates with the backend via RESTful API calls.
- **Server (Backend):** A Node.js/Express.js application that handles business logic, interacts with the MySQL database via the Sequelize ORM, and exposes a set of secure REST API endpoints.
- **Database:** A MySQL relational database stores all persistent data, including users, products, and orders.

[External Services (Twilio API)]

Implementation Plan:
The project followed an iterative development approach:
1.  **Foundation & Setup:** Initialized the Node.js backend and React frontend projects. Set up the database connection with Sequelize and defined the core User model.
2.  **Authentication & RBAC:** Implemented user registration, login, and a JWT-based authentication middleware to protect routes and identify user roles.
3.  **Feature Development (by Role):**
    -   **Seller:** Developed product creation, update, and management features.
    -   **Retailer:** Developed product browsing, cart (conceptual), and order placement features.
    -   **Admin:** Developed the user management dashboard and statistical endpoints.
4.  **Integration & Debugging:** Connected the frontend components to the backend APIs, integrated the Twilio SMS service, and performed extensive debugging to resolve issues across the stack.
5.  **Finalization:** Refined the UI/UX and prepared the final codebase.
