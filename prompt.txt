                    LOCALB2B - B2B MARKETPLACE PLATFORM

Create a comprehensive B2B marketplace platform called "LocalB2B" that connects local sellers and retailers. The platform should be built with modern web technologies and include all the features specified below.

## TECHNOLOGY STACK REQUIREMENTS

### Frontend (Client)
- React 18 with JavaScript (NOT TypeScript)
- Vite for build tooling and development server
- React Router DOM v7.9.1 for routing
- TanStack Query v5.8.4 for server state management
- React Hook Form v7.47.0 with Zod v3.22.4 validation
- Tailwind CSS v3.4.17 for responsive styling
- Chart.js v4.4.0 with react-chartjs-2 v5.2.0 for analytics
- Lucide React v0.292.0 for consistent iconography
- Wouter v2.12.1 as additional routing option

### Backend (Server)
- Express.js v5.1.0 with Node.js
- MySQL database with Sequelize ORM v6.37.3
- JWT (jsonwebtoken v9.0.2) for authentication
- Multer v2.0.2 for file upload handling
- bcryptjs v3.0.2 for password hashing
- PDFKit v0.15.0 for invoice generation
- Twilio v5.2.0 SDK for SMS notifications
- CORS v2.8.5 for cross-origin requests
- dotenv v17.2.2 for environment variables

## DATABASE SCHEMA

Create MySQL database with Sequelize models:

### Users Table
```javascript
{
  id: UUID (Primary Key),
  email: STRING (Unique, Not Null),
  password: STRING (Hashed, Not Null),
  role: ENUM('seller', 'retailer', 'admin'),
  firstName: STRING (Not Null),
  lastName: STRING (Not Null),
  businessName: STRING,
  businessType: ENUM('Manufacturing', 'Trading', 'Service Provider', 'Distributor'),
  address: STRING (Not Null),
  pincode: STRING (Not Null),
  phone: STRING,
  whatsapp: STRING,
  isActive: BOOLEAN (Default: true),
  createdAt: DATE,
  updatedAt: DATE
}
```

### Products Table
```javascript
{
  id: UUID (Primary Key),
  sellerId: UUID (Foreign Key to Users),
  name: STRING (Not Null),
  description: TEXT (Not Null),
  category: ENUM('electronics', 'machinery', 'furniture', 'food', 'textiles', 'chemicals', 'other'),
  price: DECIMAL(10,2) (Not Null),
  moq: INTEGER (Not Null),
  unit: STRING (Default: 'pieces'),
  brand: STRING,
  leadTime: INTEGER,
  images: JSON (Array of image paths),
  isActive: BOOLEAN (Default: true),
  createdAt: DATE,
  updatedAt: DATE
}
```

### Orders Table
```javascript
{
  id: UUID (Primary Key),
  retailerId: UUID (Foreign Key to Users),
  sellerId: UUID (Foreign Key to Users),
  productId: UUID (Foreign Key to Products),
  quantity: INTEGER (Not Null),
  unitPrice: DECIMAL(10,2) (Not Null),
  totalAmount: DECIMAL(10,2) (Not Null),
  status: ENUM('pending', 'ordered', 'shipped', 'out_for_delivery', 'delivered', 'cancelled'),
  orderDate: DATE (Default: NOW),
  shippedDate: DATE,
  deliveredDate: DATE,
  invoicePath: STRING,
  notes: TEXT,
  createdAt: DATE,
  updatedAt: DATE
}
```

### OrderTimeline Table
```javascript
{
  id: UUID (Primary Key),
  orderId: UUID (Foreign Key to Orders),
  status: ENUM('pending', 'ordered', 'shipped', 'out_for_delivery', 'delivered', 'cancelled'),
  message: STRING,
  occurredAt: DATE (Default: NOW)
}
```

## API ENDPOINTS SPECIFICATION

### Authentication Routes
```
POST /api/auth/register - User registration
POST /api/auth/login - User login
GET /api/auth/me - Get current user profile
POST /api/auth/logout - User logout
POST /api/auth/forgot-password - Password reset request
POST /api/auth/reset-password - Password reset confirmation
```

### Product Routes
```
GET /api/products - Get products with filters (search, category, pincode)
GET /api/products/featured - Get featured products
GET /api/products/:id - Get single product details
POST /api/products - Create new product (sellers only)
PUT /api/products/:id - Update product (seller only)
DELETE /api/products/:id - Delete product (seller only)
```

### Order Routes
```
POST /api/orders - Create new order (retailers only)
GET /api/retailer/orders - Get retailer's orders
GET /api/seller/orders - Get seller's orders
PUT /api/orders/:id/status - Update order status (sellers only)
GET /api/orders/:id - Get order details
GET /api/orders/:id/timeline - Get order timeline
```

### User Management Routes
```
GET /api/users/profile - Get user profile
PUT /api/users/profile - Update user profile
GET /api/admin/users - Get all users (admin only)
PUT /api/admin/users/:id/status - Update user status (admin only)
DELETE /api/admin/users/:id - Delete user (admin only)
```

### File Upload Routes
```
POST /api/upload/images - Upload product images
DELETE /api/upload/images/:filename - Delete uploaded image
GET /api/invoices/:filename - Download invoice PDF
```

### Analytics Routes
```
GET /api/seller/stats - Get seller analytics
GET /api/admin/stats - Get platform analytics
GET /api/orders/stats - Get order statistics
```

## WORKFLOW IMPLEMENTATION

### 1. Order Workflow
```
Retailer places order → Order status: "ordered"
↓
Seller accepts order → Status remains "ordered"
↓
Seller ships order → Status: "shipped" + Generate invoice + Send SMS
↓
Seller updates to out for delivery → Status: "out_for_delivery" + Send SMS
↓
Seller marks delivered → Status: "delivered" + Send SMS
```

### 2. SMS Workflow
```javascript
// Implement these exact SMS triggers:
1. When status changes to "shipped":
   - Generate PDF invoice
   - Send SMS: "Your order #[ID] has been shipped. Invoice available for download."

2. When status changes to "out_for_delivery":
   - Send SMS: "Your order #[ID] is out for delivery. Expected delivery today."

3. When status changes to "delivered":
   - Send SMS: "Your order #[ID] delivered successfully. Thank you!"
```

### 3. Invoice Generation Workflow
```javascript
// PDFKit implementation requirements:
1. Trigger: When order status changes to "shipped"
2. Generate PDF with:
   - Company header and branding
   - Order details (product, quantity, price)
   - Seller and retailer business information
   - Total amount and taxes
   - Invoice number (sequential)
   - Date and terms
3. Save to /server/invoices/ directory
4. Update order record with invoice path
5. Make downloadable via API endpoint
```
